# شروكتي 💗

تجربة رومانسية تفاعلية خاصة بمحمد ولارا — عالم سينمائي صغير: رسائل، ذكريات، **محمد AI**، لعبة «اضرب محمد»، موسيقى، وباب لا يظهر لمن لا يعرفه.

كل شيء يعمل محليًا على جهازك: **Flask (بايثون) + SQLite + HTML/CSS/JS صرف** (بدون React أو Vue أو Angular).

---

## ١) التثبيت والتشغيل

المطلوب: **Python 3.10 أو أحدث**.

```bash
cd shrokti
python -m venv venv
# ويندوز:        venv\Scripts\activate
# ماك/لينكس:     source venv/bin/activate
pip install -r requirements.txt
python app.py
```

ثم افتح: **http://localhost:5000**

> اختصار: شغّل `start.bat` (ويندوز) أو `./start.sh` (ماك/لينكس) وسيفعلان كل ما سبق تلقائيًا.

خيارات التشغيل (متغيّرات بيئة اختيارية):

| المتغيّر | الغرض | الافتراضي |
|---|---|---|
| `PORT` | المنفذ | `5000` |
| `HOST` | العنوان. استعمل `0.0.0.0` لفتحه من الهاتف على نفس الشبكة | `127.0.0.1` |
| `SHROKTI_DB` | مسار ملف قاعدة البيانات | `database/shrokti.db` |
| `SHROKTI_UPLOADS` | مجلد الصور والتسجيلات المرفوعة | `uploads/` |
| `SHROKTI_SECRET_KEY` | مفتاح توقيع الجلسات | يُولَّد تلقائيًا |
| `SHROKTI_HTTPS=1` | عند تشغيله خلف HTTPS فعّل الكوكيز الآمنة | `0` |

> **الميكروفون:** المتصفحات لا تسمح بالتسجيل الصوتي إلا على `localhost` أو عبر `https`. فتح التطبيق من الهاتف عبر `http://192.168...` سيعمل كل شيء فيه عدا التسجيل الصوتي. للتسجيل من الهاتف استعمل نفقًا آمنًا (مثل Cloudflare Tunnel أو ngrok) أو شهادة https.

## ٢) قاعدة البيانات

لا حاجة لأي إعداد: عند أول تشغيل يُنشئ التطبيق الملف `database/shrokti.db` وكل الجداول تلقائيًا (نظام هجرات بسيط في `backend/db.py`).

الجداول: `users` · `memories` · `messages` · `ai_messages` (سجل محادثات محمد AI) · `unanswered_questions` · `game_progress` · `schema_meta`.

الذكريات والرسائل والتقدّم في اللعبة والمحادثات **تبقى** بعد تحديث الصفحة وإغلاق المتصفح وإعادة تشغيل الخادم. للنسخ الاحتياطي انسخ `database/shrokti.db` ومجلد `uploads/`.

## ٣) أين تضع ملفاتك؟

المجلدات كلها **جاهزة ويُنشئها التطبيق تلقائيًا**. ضع ملفاتك فقط بهذه الأسماء **بالضبط** (لا تغيّرها):

| الملف | المسار |
|---|---|
| موسيقى شاشة القفل | `assets/audio/lock-screen/louk.mp3` |
| موسيقى التطبيق الرئيسية | `assets/audio/app/pack.mp3` |
| موسيقى «غرام» (داخل الذكريات) | `assets/audio/memories/lara.mp3` |
| صورة محمد في اللعبة | `assets/images/muhammad/game/mohammed.png` |
| صورة محمد الحزينة | `assets/images/muhammad/sad/mohammedsad.png` |
| صورة الذكريات | `assets/images/memories/we.png` |

- أي ملف ناقص **لا يكسر التطبيق**: تظهر بدل الصور رسومات احتياطية أنيقة، ويعرض قسم «الصوت» أن الملف غير موجود.
- لاستبدال ملف: ضع الجديد بنفس الاسم فوق القديم ثم حدّث الصفحة (Ctrl+F5).
- الموسيقى: `louk.mp3` تُسمع في شاشة القفل، `pack.mp3` بعد فتح القفل، و`lara.mp3` عند دخول الذكريات (وتعود `pack.mp3` عند الخروج). **لا توجد مؤثرات صوتية، موسيقى فقط.**
- إن منع المتصفح التشغيل التلقائي تظهر زر «اضغط لتشغيل الموسيقى»، كما تبدأ الموسيقى مع أول لمسة.
- ملفات المستخدمين (صور وتسجيلات الذكريات) تُحفظ في `uploads/` وليس في `assets/`.

## ٤) نظام الذكريات

- من **✨ إنشاء ذكريات خاصة** يكتب أي من المستخدمَين نصًا، ويضيف صورة و/أو تسجيلًا صوتيًا (من الميكروفون مباشرة) ثم يحفظ. **لا يوجد أي خيار للظهور أو الخصوصية.**
- الذكرى تُحفظ في جدول واحد (`memories`)، فتظهر **تلقائيًا** في **📖 الذكريات** وفي الغرفة المخفية، لأن الواجهتين تقرآن الجدول نفسه. لا تعديل كود ولا علامات يدوية.
- لا توجد أزرار تعديل أو حذف للذكريات عمدًا.
- الصور تُعاد معالجتها في الخادم (تُزال بيانات EXIF وتُصغَّر)، والصوت يُتحقق من نوعه الحقيقي قبل حفظه بأسماء عشوائية.

**الغرفة المخفية:** لا يوجد لها عنصر في القوائم ولا رابط ولا مسار عام. تُفتح فقط من داخل نص الصفحة الرئيسية (كلمة عادية المظهر تمامًا)، ثم رمز سري يتحقق منه الخادم. الملفات التي تبني الغرفة (`private/`) لا تُرسَل للمتصفح إلا بعد نجاح التحقق. بداخلها تبويب لـ **الأسئلة التي لم يعرف محمد AI جوابها** يمكن كتابة جواب لها.

## ٥) محمد AI وكيف تضيف معلومات

محمد AI **لا يعتمد على أسئلة محفوظة حرفيًا**: يطبّع النص العربي (تشكيل، همزات، تكرار الحروف مثل «كتيررر»)، ينزع السوابق واللواحق، يقيّم المواضيع في قاعدة المعرفة، ويركّب الجواب من الحقائق الموجودة فقط بلهجة شامية. يفهم اختلاف الصياغة («شو بيحب محمد؟» / «ماذا يحب محمد؟» / «ايش الأشياء اللي يحبها؟»)، ويفرّق بين:

- **المعروف صراحةً** (يجيب به)،
- **ما يُستنتج من حقائق معروفة** (يلخّصه دون اختراع)،
- **المجهول** (يقول بصراحة إنه لا يعرف).

عند الجهل يقول ذلك، **ويحفظ السؤال صامتًا** في `unanswered_questions` (السؤال، من سأل، الوقت، الحالة، والجواب لاحقًا). تراها من الغرفة المخفية → «أسئلة تنتظر جوابًا»؛ وإذا كتبت جوابًا لسؤال، يستعمله محمد AI في المرة القادمة لأي صياغة مشابهة.

يتذكر المحادثات السابقة (تُحفظ في `ai_messages` لكل مستخدم): يفهم «وكمان؟»، و«شو سألتك قبل؟»، ويلاحظ تكرار السؤال.

### ملف المعرفة: `data/muhammad/muhammad.json`

يُعاد تحميله **تلقائيًا** عند تعديله (بدون إعادة تشغيل). الهيكل:

```json
{
  "topics": [
    {
      "id": "interests",              // معرّف الموضوع
      "tone": "casual",               // casual = مرح | personal = أهدأ وأكثر اهتمامًا
      "intro": ["بيحب"],              // جملة تمهيدية (يُختار منها عشوائيًا)
      "keywords": ["هوايات", "اهتمامات"],   // كلمات تدلّ على الموضوع
      "phrases": [ { "re": "شو هواياته", "weight": 8 } ], // تعابير نمطية (regex) اختيارية
      "facts": [
        {
          "id": "interests.football",
          "kind": "item",             // item = يدخل في قائمة | statement = جملة مستقلة | detail = يظهر فقط عند السؤال عنه
          "text": "كرة القدم ⚽",      // نص قصير للقوائم
          "sentence": "بيحب كرة القدم ⚽", // جملة كاملة للإجابات المحددة
          "sentence_lara": "…",       // (اختياري) صيغة تخاطب لارا
          "polarity": "pos",          // pos = يحب | neg = يكره (لجواب أيوه/لأ)
          "keywords": ["فوتبول", "كوره", "ماتش"] // كلمات تدلّ على هذه الحقيقة
        }
      ]
    }
  ]
}
```

**لإضافة معلومة جديدة:** أضف كائنًا داخل `facts` لموضوع موجود (أو أنشئ موضوعًا جديدًا)، واكتب لها `keywords` بصيغ مختلفة، ثم احفظ. الكلمات تُطبَّع تلقائيًا، فلا داعي لكتابة كل الصيغ (البادئات مثل «ال/ب/و» واللواحق مثل «ه/ها» تُعالَج).

**الأسئلة التفصيلية المجهولة** (لون مفضّل، أكل، فريق...) معرّفة في `detail_traps`؛ عندما تضيف حقيقة فيها الكلمة نفسها (مثلًا «فريق») يتوقف الفخ ويجيب محمد AI بما أضفته.

> المعلومات الحالية في الملف هي **فقط** ما زوّدتَ به المشروع، ولا يضيف المحرك شيئًا من عنده.

## ٦) الأمان

- كلمتا السر (القفل والغرفة) **لا تُحفظان كنص**: بصمات PBKDF2 مملّحة في `config.py`، والتحقق يتم في الخادم فقط باستعمال `hmac.compare_digest`. لا يوجد أي رمز سري في HTML أو JS أو localStorage.
- حدّ للمحاولات الخاطئة (5 ثم انتظار دقيقة).
- جلسات موقّعة (HttpOnly + SameSite=Lax)، وفحص `Origin` للطلبات، وسياسة CSP ورؤوس أمان.
- كل مسارات البيانات محمية في الخادم بحسب الحالة (مقفل / مفتوح / غرفة مخفية)، والاستعلامات كلها مُعامَلة (parameterized).
- رفع الملفات: فحص النوع الحقيقي، حدود للحجم، أسماء عشوائية، ومعالجة الصور بـ Pillow.
- الغرفة المخفية تنتهي صلاحيتها بعد 30 دقيقة أو عند الخروج منها.

**تغيير كلمة سر:**

```bash
python tools/make_password_hash.py
```

ضع الناتج في `config.py` (`LOCK_PASSWORD_HASH` أو `HIDDEN_PASSWORD_HASH`) أو في متغيّر البيئة `SHROKTI_LOCK_HASH` / `SHROKTI_HIDDEN_HASH`.

## ٧) إعادة تشغيل التطبيق (الزر)

زر **إعادة تشغيل التطبيق** (في الشريط العلوي وفي القائمة الجانبية/«المزيد») **لا يعيد تشغيل خادم بايثون**؛ يعيد تجربة المستخدم: يوقف الموسيقى، يمسح جلسة الدخول، يعود لشاشة القفل ويطلب الرمز من جديد، وبعد الفتح يُشغَّل `pack.mp3` من البداية. البيانات المحفوظة لا تتأثر.

## English summary

**Shrokti** is a private Arabic (RTL) romantic web experience for Muhammad & Lara built with Flask + SQLite + vanilla JS. Install with `pip install -r requirements.txt`, run `python app.py`, open `http://localhost:5000`. Put your assets in `assets/…` using the exact filenames listed above; missing assets are handled gracefully. Passwords are stored as salted PBKDF2 hashes and verified server-side only (see `config.py`, `tools/make_password_hash.py`). Muhammad's knowledge lives in `data/muhammad/muhammad.json` and is hot-reloaded.
